# API Documentation

## Voice
- `POST /api/voice/callback/` — Africa's Talking voice callback

## SMS
- `POST /api/sms/callback/` — Africa's Talking SMS callback

## USSD
- `POST /api/ussd/callback/` — Africa's Talking USSD callback

## Weather
- `GET /api/weather/current/?location=<city>` — Current weather

## Farmers
- `GET /api/farmers/dashboard/` — Farmer dashboard
- `GET /api/farmers/profile/<id>/` — Farmer profile
- `GET /api/farmers/login/` — Login page

## Payments
- `GET /api/payments/status/<transaction_id>/` — Payment status

## Analytics
- `GET /api/analytics/summary/` — Usage summary
